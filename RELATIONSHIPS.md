# CROSS-SYMBOL ORB RELATIONSHIP ANALYSIS

## PURPOSE

Study historical association between ORB events in different symbols.

This module does not establish causation.

---

# REFERENCE SYMBOL

Example:

SPY

---

# TARGET SYMBOLS

Example:

AAPL
NVDA
MSFT
AMD

---

# QUESTIONS

For a bullish ORB in the reference:

* Does the target also break bullish?
* Does the target break bearish?
* Does the target not break?
* How long until the target breakout?

Same analysis applies to bearish reference events.

---

# LEAD/LAG

Analyze:

```text
0m
1m

15m
```

---

# METRICS

Calculate:

```text
sample size
same-direction frequency
opposite-direction frequency
conditional frequency
average delay
median delay
```

---

# FOREX

Do not assume bullish/bearish directions have identical economic meaning across currency pairs.

Account for quote orientation.

Document any inverse relationship treatment.

---

# COMMON DATASET

Relationship analysis should use the common historical period shared by the relevant symbols.

---

# NO CAUSALITY

The system must use language such as:

"historically associated with"

rather than:

"caused"

or:

"predicts"

unless a separate causal research methodology is explicitly introduced.
